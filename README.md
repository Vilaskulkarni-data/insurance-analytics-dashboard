# Insurance Analytics Dashboard

An Insurance Analytics project focused on analyzing insurance business data and building interactive dashboards using Excel, Power BI, and Tableau.

## Project Overview

The project analyzes insurance business activities and key performance indicators to understand business performance across different categories such as cross-sell, new business, renewals, meetings, invoices, and policy activity.

## Objectives

- Analyze insurance business performance using key metrics.
- Clean and prepare data for analysis.
- Create KPI-based analytical summaries.
- Build interactive dashboards for easier interpretation of business data.
- Present insights through Excel, Power BI, and Tableau.

## Data Preparation

The data was cleaned and prepared before analysis to improve data quality and make it suitable for dashboard development and KPI analysis.

## KPIs & Analysis

The project covers analysis of:

- Cross-sell performance
- New business
- Renewals
- Meetings
- Invoices
- Policy activity
- Other relevant business performance metrics

## Tools & Technologies

- Microsoft Excel
- Power BI
- Tableau
- Pivot Tables
- KPI Analysis
- Data Cleaning
- Data Visualization

## Dashboards

### Excel Dashboard

The Excel dashboard provides KPI-based analysis and visual summaries of insurance business performance.

### Power BI Dashboard

The Power BI dashboard provides interactive visualizations for exploring insurance business metrics.

### Tableau Dashboard

The Tableau dashboard presents insurance analytics through interactive visualizations and business performance views.
